- **[pitfall]** dm-worktree.sh create's freshness guard reuses dm-sync.sh, which deliberately SKIPs (never FF-syncs) the distro's own clone -- so a stale local main only ever advanced when the operator pulled by hand, and create silently based new distro worktrees on it (only a dm_warn 'base may be stale' nobody read). Fixed: create now special-cases repo==dockmaster, fetching origin/<default> directly (remote-tracking ref only, clone never moves) and basing off that; a failed fetch now dm_dies instead of warning. Every create now also prints 'base: <ref> @<sha>' plainly.  _(2026-07-29T12:17:57Z)_
