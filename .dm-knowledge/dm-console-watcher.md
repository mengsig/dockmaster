- **[pitfall]** Backgrounding a shell function wrapper (b() { "$ROOT/bin/$@"; } used with &) makes $! the wrapper subshell's pid, not the invoked script's own pid - a script has its own shebang and forks again as a child. Capture $! only from a DIRECT unwrapped invocation when the pid must later be used to identify/kill the real process.  _(2026-07-26T18:08:24Z)_
- **[pitfall]** A process-identity check via 'ps -p PID -o args= | grep PATTERN' must anchor with $ (end of line/string): a caller invoked as 'bash -c "<huge script>"' has the WHOLE script text as its args, and an unanchored grep matches any substring mentioned inside it (e.g. a comment or echo naming the target command), producing a false-positive identity match. Anchor the pattern to how the target is ACTUALLY invoked (its trailing arguments), not just its presence anywhere in the line.  _(2026-07-26T18:08:24Z)_
- **[pitfall]** kill on a bash process blocked synchronously on a foreground child does NOT kill that child - SIGTERM only signals the pid given, and the child gets reparented/orphaned, continuing to run (and hold any open watches/fds) indefinitely. A process wrapping a blocking child in a loop must background the child explicitly (cmd & child=$!; wait "$child") and kill that pid too in its own EXIT/INT/TERM trap, or every external kill of the wrapper leaks the child.  _(2026-07-26T18:08:24Z)_
- **[convention]** dm-ui.sh watch (added for #console-watcher) is a persistent poll loop meant to run under a Monitor (one wake per delivered poll drain - poll.js now drains everything queued per call, so one wake can carry more than one operator message). It polls in DM_UI_WATCH_TIMEOUT-second slices (default 300) rather than blocking unbounded, so an idle timeout (poll exit 3) is a normal, silent, loop-again outcome alongside a delivered drain (exit 0) - only a genuinely broken inbox (any other exit) is fatal. This bounds how long any one underlying poll.js process runs unproven-alive, trading a small periodic process-restart cost for a real liveness checkpoint.  _(2026-07-26T18:08:24Z)_
